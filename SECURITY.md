# Security policy

## Supported versions

Security fixes are made on the latest commit on `main`. This project does not
currently publish versioned releases.

## Reporting a vulnerability

Please use GitHub's **Security** tab to submit a private vulnerability report.
Include the affected code, impact, reproduction steps, and any suggested fix.

Do not disclose vulnerabilities in a public issue or pull request. If private
vulnerability reporting is unavailable, open a public issue asking for a private
contact channel without including exploit details.

Do not test against a bot, Telegram group, Cloudflare account, or database you do
not own or have explicit permission to test.
